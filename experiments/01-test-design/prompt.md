# Experiment 01 — LLM-Assisted Test Design

Act as a Software QA Engineer.

Analyze the following software requirement and derive test scenarios for the login functionality.

The scenarios should cover:
- Positive cases
- Negative cases
- Input validation
- Relevant edge cases, where justified

For each test scenario, provide:
- Scenario ID
- Title
- Objective
- Preconditions
- Test data
- Expected result

Do not write automation code.

Do not invent requirements or application behavior that is not supported by the specification.

Requirement:

# Login

## Requirement

The application provides a login form that requires a username and password.

A user with valid credentials should be successfully authenticated and granted access to the application.

A user with invalid credentials should not be authenticated and should receive appropriate feedback.

## Scope

The scope of this experiment is limited to the login functionality.

The experiment should consider both positive and negative scenarios.
